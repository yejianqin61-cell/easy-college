# easy-review

**课件进，复习笔记出——开头一张知识结构图，正文条目化，所有习题集中在文末一个自测专栏。**

`easy-review` 读的是和 [`easy-learning`](./easy-learning.md) 同一份课件，但**刻意**产出另一种文档。
一份复习笔记不是缩短版的学习笔记，而是另一种形态：它服务的是一个已经学过、需要重新定位、重新核对、
以及自我检测的读者。

| | |
|---|---|
| 技能文件 | [`skills/easy-review/SKILL.md`](../../skills/easy-review/SKILL.md) |
| 触发方式 | 模型自行调用——描述任务，或说明你是在复习 |
| 输入 | 与 `easy-learning` 相同的课件：`.pdf`、`.pptx`、`.docx`、`.md`、`.txt` |
| 产出 | `./notes/<课件名>/`：`<name>.review.md`、`<name>.review.mindmap.svg`、`<name>.review.pdf` |
| 依赖 | Python 3 + `pymupdf`；`pandoc`；出 PDF 需要 Edge 或 Chrome |

## 四条规则让它成为"复习笔记"

**1. 它以导图开头。** 标题之后第一眼就是整讲的图。复习的人是带着"我大概知道"来的，需要知道的是自己
现在站在哪儿。

**2. 知识被完整地提取成条目。** 正文是一次**完整**的条目化扫掠：每一页保留页上的每个知识点，一条
一点，编号，挂在拥有它的模块下。每个点都被**判定**成一个形态——定义、规则清单、对照表、流程、公式
块、易错点——写成你可以逐条打勾的东西。把散文改写成条目是工作；删掉一条不是。

**3. 正文里不出现任何题目。** 课件里所有习题都挪到最后。复习的人在正文中间碰到一道题，要么去解它
（于是跑题），要么跳过它（于是把自己训练成习惯跳过）。两种都不是复习。

**4. 自测专栏在最后，而且它承载全部。** 一个章节，在最末尾，装着课件提出的每一道题，每道都有引用的
题干和紧随其后的答案，每条都带页码。它同时是复习工具**和**覆盖度证据：题目就是课件自己对"什么重要"
的陈述。

## 什么时候用它

只要材料你已经熟悉，就用它：

- *"我已经学过一遍了，出份复习笔记。"*
- *"复习资料"* / *"考前复习"* / *"二轮复习"* / *"考点整理"* / *"知识梳理"*
- *"题目全部放到最后。"* ——光是这一句就足以选中这个技能。
- *"把这个讲义整合成考前复习材料。"*
- *"给这份课件做一张知识结构图。"*

## 产出，逐部分看

```
# <课件名> — 复习笔记
> 来源说明
![知识结构图](<name>.review.mindmap.svg)      ← 1. 导图
## 模块 1｜…                                  ← 2. 正文
### 1.1 …
## 复习自检｜原稿疑点与易错点                    ←    勘误表
## 自测专栏 {#selftest}                         ← 3. 全部题目
```

自测专栏带一个显式的 `{#selftest}` 锚点，因为样式表把 `h2#selftest` 变成强制分页——所以专栏永远从
新的一页开始。pandoc 会从标题文本推导 id，而文本推导出来的 id 会在语言一变的瞬间悄悄失效。

专栏内部，每道题的题干是一个引用块，答案是一个**独立的**引用块紧跟其后，而不是嵌套在里面：在文档
最后，答案必须能被一根拇指盖住，而嵌套引用块做不到——盖住答案的同时题目也没了。

## 知识结构图

```bash
python skills/easy-review/scripts/knowledge-map.py notes/my-lecture.review.md \
  --root "知识结构图" --insert --before "模块 1"
```

`#` 是根，`##` 是模块，`###` 是知识点，而 `###` 下的 `####` 子条目挂在它旁边——那些是编号的规则、
情形或模式，不是新的叶子。不是知识的章节（自测专栏、附录、勘误表）会被跳过。`--insert` 是**刷新**
引用而不是再加一条，所以改完标题可以随时重新生成。

文档标题很长时记得传 `--root`：导图的根是一个标签，一个完整的论文标题会变成一列六行的短句。

## 契约检查器

```bash
python skills/easy-review/scripts/check-review.py notes/my-lecture.review.md
```

退出码 0 表示文档遵守了自己的规则：

- 导图在第一个知识模块之前；
- 知识正文里没有残留任何题目标记或练习引导语；
- 自测专栏存在且在最后——它之后不再有模块；
- 专栏非空，且它的题目组带页码。

退出码 1 会列出违规项。它是刻意机械的，也是刻意狭窄的：它**无法**证明"覆盖全"——它看不到课件——
那是提取环节的责任，在最后口头配平。

## 怎么用好它

- **说明你是在复习。** 光说"做笔记"会被读成第一遍学习。"我已经学过一遍"或"复习"才是选中这个技能
  的信号。
- **想同时要两份就配着用。** 用第一遍的笔记学，用复习笔记复习；两者共用同一份台账、同一条页码纪律。
- **先看勘误表。** 它收集了课件自相矛盾、以及和自己答案页对不上的每一处。照着错的答案页复习，比不
  复习更糟。
- **把自测专栏当成覆盖度证据。** 如果课件问过的某道题没出现在专栏里，说明那一页的提取漏了，而最后的
  报告会说明原因。
