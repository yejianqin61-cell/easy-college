# easy-learning

**课件进，学习笔记出——每一页都有判定，每一条都有页码。**

`easy-learning` 为**第一遍学**一份讲义而产出笔记：材料整段保留，课件自带的题目就放在它考的那个知识
点旁边——因为在这个阶段，题目本身就是学材料的一部分。

如果你已经学过、只想复习，你要的是 [`easy-review`](./easy-review.md)。

| | |
|---|---|
| 技能文件 | [`skills/easy-learning/SKILL.md`](../../skills/easy-learning/SKILL.md) |
| 触发方式 | 模型自行调用——描述任务，或直接上传课件 |
| 输入 | `.pdf`、`.pptx`、`.docx`、`.html`、`.htm`、`.md`、`.txt` 讲义材料 |
| 产出 | `./notes/<课件名>/`：笔记（`.md` + `.pdf`）、思维导图（`.svg`）、台账、页面渲染图，HTML 另附逐单元文本 |
| 依赖 | Python 3（HTML 分诊只用标准库）；PDF 需要 `pymupdf`；`pandoc`；出 PDF 需要 Edge 或 Chrome |

## 什么时候用它

材料对你来说是新的，或者你想保住原始材料时：

- *"把这份课件整理成笔记。"*
- *"整理成笔记"* / *"提炼知识点"* / *"划重点"* / *"讲义总结"*
- *"Extract the key points from these slides."*
- *"Pull the quiz questions out of this lecture."*
- *"这是我第一次学这个。"*

它也可以作为组件被调用：任何需要"从讲义里挖知识点或自测题"的技能，都可以把这件事交给它。

## "信得过的笔记"是什么意思

两条不变式在干活。

**每一页都有判定。** 漏页正是这个技能存在的意义，所以每份输入的每一页都会落进**台账**：判定
（`readable` / `needs-vision` / `needs-human`）、命中的陷阱、保留还是剔除、理由码，以及它喂给了哪个
模块。台账在每一步都自我配平——*行数 = 各输入页数之和*。

**每一条都有页码。** 任何知识点、公式、表格、题目、勘误，进入笔记时都必须带上它来自的页码。你可以
翻到课件那一页，找到同样的内容。这是笔记"可核查"而不是"听起来对"的原因。HTML 课件没有页码对象，
"一页"由分诊当场判定并记进台账的 `page_model`，单元编号 `s01`、`s02`……就是这个课件的引用体系。

再加一条"不越界"：**忠于原文是默认值。** 判定为保留的页面会**整页**进入笔记。技能负责重组，不负责
替你决定什么不需要。只有背景性内容可以被剔除——动机、类比、封面、分节页、休息页——每一条都带理由
码，也都会在最后列出来供你否决。

## 流程

| 步骤 | 做什么 |
|---|---|
| 0 | 清点输入，为每种格式确认提取器**和**渲染器，缺什么装什么，并**真的打开一个文件**、打印页数来验证 |
| 1 | 逐页分诊进台账，标出命中的陷阱族 |
| 2 | 只剔除背景，每个被剔除的页面给理由码 |
| 3 | 提炼知识点；公式从页面渲染图重建，绝不从坏掉的文本层照抄 |
| 4 | 收集课件自带的题目——**没给答案的题最值钱** |
| 5 | 成稿：模块、知识点、题目紧跟考点、全程带页码，开头用生成的知识结构图 |
| 6 | 出 PDF，并抽查导图、公式和中文是不是真的渲染出来了 |
| 7 | 报台账的两个尾巴——看不清的页面、被剔除的页面——并当场配平页数 |

## 为什么它不是"文本提取器"

朴素提取器会在真实大学课件上以各种方式失败，产出"自信但错误"的笔记。这些失败模式的目录——每个都有
检测特征、恢复办法，以及来自两份真实课件的实证——在
[`references/traps.md`](../../skills/easy-learning/references/traps.md)。几个代表：

- **隐形文字。** 两个文本片段重叠，其中一个被后绘制的不透明图形盖住。页面上看不见，文本层里却有。
  有一份课件在 16 页里各藏了一个 `34`，把 15 个元素的数组变成 19 个，足以生成一整套关于"不存在的
  数据"的练习题。
- **公式乱码。** 内嵌数学字体没有 `ToUnicode` 映射，抽出阿拉伯文和私用区码位：`T(n) = an + b` 抽成
  `ܶ(݊) = ܽ݊ + ܾ`。
- **满版位图课件。** 每页都是一整张背景位图时，"位图占比"这个信号彻底失效，按占比设阈值会命中封面，
  却漏掉真正要紧的页。技能改用文字密度判断。
- **原稿本身有错。** 课件自相矛盾，或者答案页的数字和题面对不上。这些都会被标出来并附页码，而不是
  被悄悄改掉——矛盾点往往正是全页最值得考的地方。

## HTML 课件

HTML 课件不需要装任何东西：`scripts/triage-html.py` 只用标准库，写出的台账与 PDF 路径完全一致，
所以分诊之后的一切都不变。

不同的是，HTML 文件本来没有"页"，所以由分诊来判定"一页"是什么，并把判定说出来：先找 slide 类名或
`data-slide` 属性，再找 `<section>`，再找同一标签的连续兄弟节点，再看顶级标题，最后才把整份文件当成
一个单元。选中的模型会打印出来并记入 `page_model`，它编出的单元号就是这个课件的引用体系：写 `(s03)`
而不是 `(p42)`。判定错了就用 `--slide-selector "section.slide"` 自己指定元素。

除台账之外它还会写 `<name>.slides.md`——课件的文本层，一个单元一块——提炼步骤读的就是它。这份文本明确
分开三条通道，因为在 HTML 里它们确实是不同的东西：

- **单元正文**：只有它可以被知识点引用；
- **隐藏文本**：`hidden`、`display:none`、`class="hidden"`、`<template>`。它在文件里、不在屏幕上，而在
  课件里它往往格外值钱：答案页、范例解答、只在某种几何下才出现的控制面板、老师赶时间会跳过的那段推导
  的备用页。它得 `needs-human`，绝不会被悄悄丢掉；
- **演讲者备注**：`<aside class="notes">`。可以挖答案，但绝不当课件正文引用。

有三个 HTML 特征值得先知道再看台账：

- **手工搭出来的公式。** 用 `<span class="frac">`、`vec`、`sqrt` 拼的公式在文本层会压扁成
  `E = FEqtestEq. 2.4`。文本 dump 会把这一块的**标记**原样列出，公式因此可以精确重建，笔记里引用写成
  `(s01, rebuilt from markup)`。
- **内容在另一个文件里。** 保存下来的网页常常只是个外壳，课件在它 iframe 的那个同级文件里。分诊会给这
  一行打上 `frame-shell` 并打印该文件的路径。台账只覆盖你真正读过的文件，报告里要说清这一点。
- **幻灯片由脚本生成。** 开发服务器版本（Slidev、未构建的 Marp）文件里根本没有正文，这就是
  `js-rendered`：答案是让对方给构建产物或导出件，而不是猜。

两个假阳性已经处理，都是在真实 700 KB 实验讲义上量出来的：`aria-hidden="true"` **不是**隐藏（它只对
读屏软件隐藏，不对屏幕隐藏；没排除它之前 15 个单元里误报 12 个），以及 `<div class="feedback" hidden="">`
这种空占位符其实什么都没藏。

## 思维导图

笔记开头有一张"整讲全貌"图，由笔记自己的标题生成，所以永远不会和正文脱节：

```bash
python skills/easy-learning/scripts/mindmap.py notes/my-lecture.notes.md --insert --alt "知识结构图"
```

`#` 是根，`##` 是模块，`###` 是知识点。没有 `###` 子节点的 `##` 章节——附录、目录——会被跳过，因为
导图展示的是知识结构，而不是文档的家具。输出为独立的 **SVG**：矢量、离线、零依赖、打印锐利、文字
可选可搜。

## 怎么用好它

- **把文件给它。** 指路径比描述课件有用得多。
- **用你的语言提问。** 中文提问，主体就是中文、每个术语首次出现中英并列，而课件的原话、定义和题干
  保留英文原文；英文提问则全英文。
- **读最后那份报告。** 它会列出每一页读不出来的、以及每一页被当成背景剔除的。你否决哪一页，那一页
  就作为正文回到笔记里。
- **不要让它"精简"。** 这个技能负责重组；负责条目化的是 `easy-review`。如果你想要的是一份浓缩的
  复习文档，那是一个不同的请求，不是一个开关。

## 复习目标清单

笔记以 `## 复习目标｜考前自检清单` 收尾：每个知识点一条 `- [ ]`，按模块分组，每条都带页码。这是整份
笔记里唯一为考试而不是为阅读而写的部分——读者把已经会的打勾，剩下的就是不会的。

每条写的是**能力**，不是标题（是`能写出标准误差 $\sigma_{\bar{x}}$ 的公式并说明它与标准差 $\sigma_x$
差在哪里`，不是`标准误差`），因为上面那级标题已经把话题名说过了。它永远在正文写完之后才写。

## 双语引用课件原话

中文笔记里，课件的原话保留英文——那是考卷会用的措辞——中文放在同一引用块的下一段：

```markdown
> **Accuracy** is the closeness of agreement between a measured value and a true or accepted value. (p19)
>
> 译：准确度是指测量值与真值（或公认值）的接近程度。(p19)
```

那个空的 `>` 行是关键：没有它，markdown 会把两行软换行成一段，译文就读成了英文的延续。
